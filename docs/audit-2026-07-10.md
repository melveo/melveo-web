## Executive summary

Web je v **nejlepším stavu za celou dobu**: Core Web Vitals výborné (LCP 780 ms na
throttled mobilu, CLS 0.006), responsivita čistá na všech 11 testovaných
viewportech (320 → 2560 px), SEO kompletní, CSP **enforced** (už ne report-only),
custom rAF scroll controller je nasazený (Motion pryč z morph sekce).

Zbývají **dvě velké příležitosti** a hrst menších:

1. 🥇 **Obrázky: 1,7 MB na homepage — přitom stačí ~500 KB.** Thumbs (720×900)
   jsou správně dimenzované, ale slabě komprimované (q≈90; 100–190 KB/kus).
   Re-encode na q70 ušetří ~1,2 MB *a zároveň* sníží decode-jank v morph sekci.
2. 🥈 **Morph sekce má pořád frame spiky** (p95 288 ms na 1440px desktopu,
   max 4,6 s při 4× CPU throttlingu). Hlavní podezřelý po odstranění Motion:
   dekódování těžkých thumbů uprostřed scroll reveal + paint clipnutých hexagonů.
   Oprava #1 tomu přímo pomůže; zbytek řeší `content-visibility` + decode-ahead.

## 1. Core Web Vitals (živé měření, Playwright + CDP)

| Profil | TTFB | FCP | LCP | CLS | load |
|---|---:|---:|---:|---:|---:|
| Mobil 390px, 4× CPU throttle, slow-4G | 88 ms | 780 ms | **780 ms** | **0.006** | 4,2 s |
| Desktop 1440px, bez throttlingu | 150 ms | 292 ms | **292 ms** | **0.006** | 0,6 s |

Hodnocení: **LCP i CLS hluboko v zelené zóně** (Google prahy: LCP < 2,5 s,
CLS < 0,1). LCP je hero headline (text) — proto tak rychlé. Výrazné zlepšení
proti červnovému auditu (Lighthouse LCP 5,3 s CS) — tehdejší LCP kandidát byla
zřejmě fotka; teď je hero čistě textové s canvas pozadím.

`load` 4,2 s na mobilu = doběh obrázků (viz §3) — CWV to nezhoršuje, ale
šetří se tím data uživatele.

## 2. Scroll výkon — morph sekce (živé měření)

Skript scrolluje přes celou morph sekci a měří rAF frame gapy:

| Profil | p50 | p95 | max | janky frames (>33 ms) |
|---|---:|---:|---:|---:|
| Desktop 1440, no throttle | 13,7 ms | **288 ms** | 320 ms | 37/216 |
| Desktop 1440, 4× throttle | 21,8 ms | 1060 ms | **4590 ms** | 60/216 |
| Mobil 390, 4× throttle | 16,2 ms | 330 ms | 384 ms | 39/172 |

- p50 je zdravé všude → **základní frame loop je v pořádku** (custom rAF
  controller potvrzený v nasazeném bundlu, žádný Motion import).
- Spiky odpovídají **image decode** (11–15 thumbů à 100–190 KB dekódovaných
  během reveal) + první hydrataci React islandu (data-flow) pod sekcí.

**Doporučení (v pořadí účinnosti):**
1. Re-encode thumbs (viz §3) — menší soubory = rychlejší decode.
2. `decoding="async"` už je; přidat **pre-decode**: po `IntersectionObserver`
   pre-warmu (rootMargin už je 640px) zavolat `img.decode()` na všechny thumby
   ještě před vstupem sekce do viewportu.
3. Zvážit `content-visibility: auto` na sekcích pod morph (odloží layout/paint
   mimo viewport).

## 5. Payload rozbor (homepage /cs/)

| Kategorie | Raw | Po gzip/br |
|---|---:|---:|
| HTML | 286 KB | 39 KB |
| — z toho 59 inline SVG | 203 KB | (komprimují se dobře) |
| CSS (2 soubory) | 111 KB | ~20 KB |
| JS initial (11 chunků) | ~23 KB | ~9 KB |
| JS lazy React island (data-flow) | **236 KB** | ~75 KB |
| Fonty (2× woff2 preload) | ~77 KB | — |
| Obrázky | **1 685 KB** | — |
| **Celkem full load + scroll** | **~5,7–5,9 MB** | |

Poznámky:
- 59 inline SVG (ikony hexagonů + data-flow) nafukuje HTML, ale gzip to řeší
  (39 KB wire). Parse cost na mobilu je malý. Nízká priorita.
- **React island 236 KB raw jen pro jednu sekci** (MelveoDataFlowHero).
  Dlouhodobě zvážit přepis na vanilla TS + GSAP (GSAP už na stránce je) nebo
  Preact compat (~10 KB místo 186 KB react-dom). Střední priorita — je lazy
  (`client:visible`), CWV to neovlivňuje.

⚠️ **K rozhodnutí (ne bug):** Cloudflare "Content Signals" v robots.txt
blokuje AI crawlery (GPTBot, ClaudeBot, CCBot, Google-Extended, Applebot-
Extended…). To chrání obsah před AI trainingem, ale **web se nebude
objevovat v odpovědích AI asistentů** (ChatGPT search, Perplexity…), což je
u B2B SaaS často relevantní discovery kanál. Je to zapnuté v CF dashboardu
(managed robots.txt) — vypnutelné tamtéž, pokud chceš AI viditelnost.

ℹ️ Root `/` vrací 200 + klientský redirect (dokumentované rozhodnutí kvůli
hreflang signálům — OK).

## 9. Provoz / proces

- 🔴 **Auto-deploy je pořád rozpojený** (Workers Builds konektor po přesunu
  účtu). Každý push na main teď vyžaduje ruční `npx wrangler deploy`.
  Fix: CF dashboard → melveo-web → Settings → Builds → připojit GitHub repo.
- 🟡 **Žádné CI** (.github/workflows) — doporučený minimální workflow:
  `bun run check` + `bun run build` + `bun audit` na PR; volitelně
  `scripts/audit-responsive.mjs` (přidán tímto auditem) proti preview.
- 🟡 Flaky lokální build (bun + sharp postinstall + ESM cache) — vyřešeno
  vždy `rm -rf node_modules && bun install && bun install`. Zvážit přesun
  sharp/playwright/resvg do optionalDependencies nebo samostatného
  `scripts/package.json`, ať neblokují web build.

## 9b. Repo hygiena (agentní analýza)

- **16 nereferencovaných full-size originálů** v `public/images/melveo-grid/`
  (~2,9 MB) — honeycomb používá jen `/thumbs/` + srcset; jediný referencovaný

  do dist/ zbytečně.
- Celý `public/images/club-flow/` (4 obrázky) — **0 referencí v src/**
  (ClubFlowStage komponenta byla smazána v květnu).
- **Finder duplikáty se deployují na produkci**: `team-briefing-wide 2.webp`,
  `club-flow/decision 2.webp`, `sessions 2.webp` jsou gitignored, ale
  `scripts/copy-public-assets.mjs` je kopíruje do dist/ → živý web.
  (Známý iCloud-Documents problém — viz memory.)
- Na disku dále: `src/components/HeroScene 2.astro`, `DataFlowStage 2.astro`,
  3× `docs/* 2.md`, `dist 2/`, `node_modules.placeholder.*`.

### Nepoužívané devDependencies
`@resvg/resvg-js`, `wawoff2`, `opentype.js` (pozůstatky OG experimentů —
finální build-og.mjs používá Playwright+sharp), `@types/three` (three samotné
už v deps není). `mdn-data` už bylo odstraněno dříve. ✅ `split-type`, `gsap`,
`playwright`, `sharp` jsou používané.

### Scroll morph — potvrzení stavu kódu
`ImageGridScrollMorph.astro` (2 447 řádků): **žádný Motion import**; custom
passive-scroll + rAF controller s lerp smoothingem (0.24/0.3), IO gating
(rootMargin 35 %) + will-change toggle, visualViewport lock proti mobile
URL-bar resize. Diagnostické `?morph=` flagy zachovány.

### Fix doporučení copy skriptu
`scripts/copy-public-assets.mjs` by měl **excludovat `* 2.*` / `* 3.*`
soubory** — jednořádkový filtr zabrání deployi Finder dupes navždy.
